1. Mem0: 프로덕션 AI 에이전트를 위한 장기 메모리 — 그래프 기반 메모리 아키텍처로 LLM의 장기 대화 일관성을 향상시키는 Mem0.

그래프 기반 메모리 아키텍처로 LLM의 장기 대화 일관성을 향상시키는 Mem0. 정보 추출, 통합, 검색을 효율적으로 수행하여 기존 메모리 시스템 대비 정확도와 계산 효율성 모두 우수. 프로덕션 환경에서 바로 사용 가능한 수준.

2. Agent READMEs: 에이전트 컨텍스트 파일 연구 — CLAUDE.

CLAUDE.md 같은 에이전트 컨텍스트 파일 2,303개를 분석한 최초의 대규모 실증 연구. 이 파일들은 정적 문서가 아니라 설정 코드처럼 진화하는 복잡한 아티팩트임을 발견. 개발자들은 기능적 컨텍스트(빌드 명령 62.3%, 구현 세부사항 69.9%)를 우선시하지만, 보안(14.5%)과 성능(14.5%) 요구사항은 거의 명시하지 않는 문제점 지적.

3. Kimi K2.5: Visual Agentic Intelligence — Kimi K2.

Kimi K2.5는 텍스트+비전 처리를 향상시킨 오픈소스 멀티모달 에이전트 모델. Agent Swarm 기법으로 병렬 태스크 실행이 가능하며, joint optimization으로 멀티모달 이해력 강화.
