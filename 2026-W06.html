1. JUST-DUB-IT: Video Dubbing via Joint Audio-Visual Diffusion — 오디오-비주얼 joint diffusion으로 비디오 더빙 자동화.

오디오-비주얼 joint diffusion으로 비디오 더빙 자동화. 양방향 cross-attention으로 음성과 영상의 정밀한 시간 동기화 달성. LTX-2 기반으로 Flow Matching 활용. 립싱크 + 음성 생성을 동시에 처리.

2. Khronos glTF Gaussian Splatting Extension — Khronos Group이 glTF 2.

Khronos Group이 glTF 2.0에 Gaussian Splatting 확장을 발표. 3D 가우시안 스플랫을 업계 표준 포맷으로 저장/전송할 수 있게 됨. 릴리즈 후보(RC) 단계로 업계 피드백 수집 중. 3DGS가 표준화되면서 게임/웹/메타버스 등 다양한 플랫폼에서 호환성 확보.

[적용 대상] 게임 엔진, 웹 3D, 메타버스 플랫폼 [파이프라인] 3D 스캔 → 3DGS 처리 → glTF 익스포트 → 멀티플랫폼 배포 [기대 효과] 3DGS 자산의 범용 호환성 확보, 워크플로우 표준화 [중요] 업계 표준이므로 빠른 도입 권장

3. Mem0: 프로덕션 AI 에이전트를 위한 장기 메모리 — 그래프 기반 메모리 아키텍처로 LLM의 장기 대화 일관성을 향상시키는 Mem0.

그래프 기반 메모리 아키텍처로 LLM의 장기 대화 일관성을 향상시키는 Mem0. 정보 추출, 통합, 검색을 효율적으로 수행하여 기존 메모리 시스템 대비 정확도와 계산 효율성 모두 우수. 프로덕션 환경에서 바로 사용 가능한 수준.

4. Agent READMEs: 에이전트 컨텍스트 파일 연구 — CLAUDE.

CLAUDE.md 같은 에이전트 컨텍스트 파일 2,303개를 분석한 최초의 대규모 실증 연구. 이 파일들은 정적 문서가 아니라 설정 코드처럼 진화하는 복잡한 아티팩트임을 발견. 개발자들은 기능적 컨텍스트(빌드 명령 62.3%, 구현 세부사항 69.9%)를 우선시하지만, 보안(14.5%)과 성능(14.5%) 요구사항은 거의 명시하지 않는 문제점 지적.

5. Kimi K2.5: Visual Agentic Intelligence — Kimi K2.

Kimi K2.5는 텍스트+비전 처리를 향상시킨 오픈소스 멀티모달 에이전트 모델. Agent Swarm 기법으로 병렬 태스크 실행이 가능하며, joint optimization으로 멀티모달 이해력 강화.

Flowing Fidelity: 효율적 고해상도 비디오 생성 — 2단계 접근으로 고해상도 비디오를 효율적으로 생성.

2단계 접근으로 고해상도 비디오를 효율적으로 생성. 1단계에서 저해상도로 프롬프트 충실도 확보, 2단계에서 Flow Matching으로 고해상도 디테일 추가. 계산 효율성과 품질을 동시에 달성.

3D 이해를 기반으로 정밀한 카메라 제어가 가능한 비디오 생성. 기존 인페인팅 방식을 넘어 실제 3D 공간 이해를 통해 카메라 움직임에 따른 자연스러운 영상 생성. 가상 촬영, 시점 변환에 활용 가능.
