Multi-Agent Collaboration via Evolving Orchestration — RL 기반 멀티에이전트 오케스트레이션 LLM 에이전트들을 '인형극(Puppeteer)'처럼 중앙에서 동적 지휘하는 새로운 패러다임. 강화학습으로 훈련된 오케스트레이터가 태스크 상태에 따라 에이전트 순서와 우선순위를 적응적으로 조정. | 항목 | 내용 | |------|------| | 📄 논문 | [arXiv:2505.19591](https://arxiv.org/abs/2505.19591) | | 💻 코드 | [GitHub - ChatDev/puppeteer](https://github.com/OpenBMB/ChatDev/tree/puppeteer) | | 🏭 적용 대상 | AI 에이전트 개발사, 자동화 솔루션 기업 | | 🔧 파이프라인 | 복잡한 워크플로우 자동화, 멀티스텝 태스크 | | ✨ 기대 효과 | 조율 비용 50% 절감, 태스크 완료율 향상 | | 🚀 실증 난이도 | ✅ 바로 테스트 가능 |
2. Kimi K2.5: Visual Agentic Intelligence — 오픈소스 멀티모달 에이전트 텍스트+비전 동시 처리가 가능한 에이전트 모델. **Agent Swarm** 기법으로 여러 에이전트가 병렬로 태스크를 수행할 수 있어 처리 속도가 크게 향상. | 항목 | 내용 | |------|------| | 📄 논문 | [arXiv:2602.02276](https://arxiv.org/abs/2602.02276) | | 💻 코드 | 오픈소스 예정 | | 🏭 적용 대상 | 비전 AI 개발, QA 자동화, 콘텐츠 분석 | | 🔧 파이프라인 | 이미지/비디오 분석 → 자동 리포트 | | ✨ 기대 효과 | 시각 자료 분석 자동화 | | 🚀 실증 난이도 | ✅ 바로 가능 (출시 후) |
3. Mem0: 프로덕션 AI 에이전트를 위한 장기 메모리 — 그래프 기반 메모리 시스템 LLM 에이전트의 장기 대화 일관성을 획기적으로 향상시키는 메모리 아키텍처. 정보 추출→통합→검색의 전 과정이 최적화되어 있으며, 프로덕션 환경에서 바로 사용 가능. | 항목 | 내용 | |------|------| | 📄 논문 | [arXiv:2504.19413](https://arxiv.org/abs/2504.19413) | | 💻 코드 | [GitHub - mem0ai/mem0](https://github.com/mem0ai/mem0) ⭐ 오픈소스 | | 🏭 적용 대상 | 챗봇 개발, AI 비서, 고객 상담 자동화 | | 🔧 파이프라인 | 대화 시스템 → 메모리 레이어 추가 | | ✨ 기대 효과 | 장기 대화 일관성 향상, 사용자 맞춤화 | | 🚀 실증 난이도 | ✅ 바로 테스트 가능 |

🤝 에이전트/자동화

Agent READMEs — 에이전트 컨텍스트 파일 2,303개 분석 연구 CLAUDE.md 같은 에이전트 컨텍스트 파일의 최초 대규모 실증 연구. 개발자들이 기능적 컨텍스트(빌드 명령 62.3%, 구현 세부사항 69.9%)는 잘 작성하지만, 보안(14.5%)과 성능(14.5%) 요구사항은 거의 명시하지 않는 문제 발견. - **시사점**: 에이전트 컨텍스트 파일에 보안 체크리스트 추가 권장 - **링크**: [arXiv:2511.12884](https://arxiv.org/abs/2511.12884)
