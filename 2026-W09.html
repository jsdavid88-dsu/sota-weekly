🔍 논문별 상세

1. 🎬 [영상] 초대형 비디오 추론 스위트 (VBVR)

원제: A Very Big Video Reasoning Suite
arxiv: 2602.20159 | Upvotes: 300

비디오 모델의 발전은 시각적 품질에 집중된 반면, 추론 능력은 상대적으로 미탐구 상태였다. VBVR 데이터셋은 200개의 정제된 추론 태스크와 100만 개 이상의 비디오 클립을 포함하며, 기존 데이터셋 대비 1000배 이상 규모다. VBVR-Bench는 규칙 기반·인간 정렬 채점으로 재현 가능한 평가를 제공하며, 초기 실험에서 미학습 태스크로의 발현적 일반화 가능성이 확인됐다.

🎯 TD 관점: ComfyUI 영상 워크플로우 평가에 직접 활용 가능한 벤치마크. video-reason.com에 공개.

2. 🧠 [AI생성] 추론 모델은 언제 생각을 멈춰야 할지 이미 알고 있다

원제: Does Your Reasoning Model Implicitly Know When to Stop Thinking?
arxiv: 2602.08354 | Upvotes: 169

대형 추론 모델(LRM)은 정답에 도달했을 때 이미 내부적으로 그것을 인지하지만, 시스템이 계속 사고하도록 강제한다. SAGE-RL 프레임워크는 모델이 적절한 시점에 자율적으로 사고를 중단할 수 있도록 강화학습으로 훈련한다. 이를 통해 불필요한 추론 토큰을 대폭 줄이면서도 정확도를 유지한다.

🎯 TD 관점: AI 추론 비용 최적화의 핵심 논문. o3/DeepSeek-R1 류 모델에 직접 적용 가능.

3. 🧠 [AI생성] VESPO: 안정적인 오프-폴리시 LLM 학습

원제: VESPO: Variational Sequence-Level Soft Policy Optimization for Stable Off-Policy LLM Training
Upvotes: 167

기존 오프-폴리시 LLM 강화학습은 학습 불안정성과 높은 분산 문제가 있었다. VESPO는 변분 추론을 시퀀스 수준에 적용해 오프-폴리시 학습의 안정성을 확보하고, 다양한 LLM 벤치마크에서 기존 방법 대비 일관된 성능 향상을 보인다.

4. 🤖 [AI생성] VLANeXt: 강력한 VLA 모델 구축 레시피

원제: VLANeXt: Recipes for Building Strong VLA Models
arxiv: 2602.18532 | Upvotes: 38

VLA(Vision-Language-Action) 모델 설계 공간을 통합 프레임워크로 체계화했다. RT-2·OpenVLA 기준에서 출발해 기반 컴포넌트, 지각 요소, 액션 모델링 등 3차원으로 설계 선택을 해부하고 12가지 핵심 발견을 도출. VLANeXt는 LIBERO 및 LIBERO-plus 벤치마크에서 SOTA 달성.

🎯 TD 관점: 부산마법소녀 캐릭터 모션 제어 파이프라인(AnimateDiff + VLA)에 참고 가능.

5. 🕹 [에이전트] SkillOrchestra: 스킬 전이 기반 에이전트 라우팅

원제: SkillOrchestra: Learning to Route Agents via Skill Transfer
arxiv: 2602.19672 | Upvotes: 27

복합 AI 시스템의 오케스트레이션은 라우팅 붕괴(routing collapse) 문제를 겪는다. SkillOrchestra는 실행 경험에서 세밀한 스킬을 학습하고, 에이전트별 역량·비용을 모델링해 최적의 에이전트를 선택한다. 10개 벤치마크에서 RL 기반 SOTA 대비 22.5% 향상, Router-R1 대비 700배 학습 비용 절감.

6. 🌐 [3D재구성] Generated Reality: 인간 중심 월드 시뮬레이션

원제: Generated Reality: Human-centric World Simulation using Interactive Video Generation with Hand and Camera Control
Upvotes: 22

손 동작과 카메라 움직임을 제어 신호로 사용하는 인터랙티브 영상 생성 프레임워크. 현실적인 3D 환경을 실시간으로 합성해 인간 중심 월드 시뮬레이션을 가능케 한다.

🎯 TD 관점: 부산마법소녀 촬영 + UE5 배경 합성 파이프라인에 직접 응용 가능성 높음 🔥

7. 🎬 [영상] TOPReward: 로봇 학습용 제로샷 보상 신호

원제: TOPReward: Token Probabilities as Hidden Zero-Shot Rewards for Robotics
arxiv: 2602.19313 | Upvotes: 21

VLA 모델의 강화학습은 희소 보상과 낮은 샘플 효율로 인해 어려움을 겪는다. TOPReward는 사전학습된 비디오 VLM의 토큰 확률을 활용해 학습 도메인을 넘어 일반화되는 시간적 가치 함수를 구성한다. 별도 학습 없이 제로샷으로 로봇 작업 진행도를 추정한다.

8. 🧠 [AI생성] Mobile-O: 모바일 기기의 통합 멀티모달 모델

원제: Mobile-O: Unified Multimodal Understanding and Generation on Mobile Device
arxiv: 2602.20161 | Upvotes: 18

기존 통합 멀티모달 모델은 모바일 환경에서 작동하기엔 너무 무겁다. Mobile-O는 단일 아키텍처 내에서 시각 이해와 생성을 동시에 처리하면서도 모바일 디바이스에서 실행 가능한 경량화를 달성한다.

9. 🕹 [에이전트] Calibrate-Then-Act: 비용 인식 LLM 에이전트

원제: Calibrate-Then-Act: Cost-Aware Exploration in LLM Agents
Upvotes: 14

LLM 에이전트의 탐색은 계산·API 비용을 무시하는 경향이 있다. Calibrate-Then-Act는 탐색 전 비용을 명시적으로 보정(calibrate)한 후 액션을 선택해, 동일 예산 내 작업 완료율을 높인다.

10. 🎬 [영상] 교차 뷰 객체 대응 자기지도 학습

원제: Learning Cross-View Object Correspondence via Cycle-Consistent Mask Prediction
Upvotes: 13

서로 다른 시점에서 촬영된 영상 간 동일 객체를 매칭하는 문제. 사이클 일관성 마스크 예측을 자기지도 학습 신호로 활용해, 레이블 없이 교차 뷰 대응을 학습한다.

🎯 TD 관점: Gaussian Splatting 기반 부산 로케이션 3D 재구성 파이프라인에 활용 가능.
