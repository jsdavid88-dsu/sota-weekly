## 1. 프로젝트 비전

### 1.1 목표
**"AI/XR/영상 기술 SOTA를 수집하고, 산업계 적용 인사이트를 담은 주간 리포트를 협력기업에 배포한다"**

### 1.2 핵심 가치
| 가치 | 설명 |
|------|------|
| **신속성** | 글로벌 최신 연구를 1주일 내 한국어로 정리 |
| **실용성** | "그래서 우리 파이프라인 어디에 쓸 수 있나?" 답변 |
| **접근성** | 웹에서 누구나 열람, 기업 담당자에게 직접 배포 |
| **전문성** | 동서대 가상융합기술연구원 브랜딩 |

### 1.3 타겟 독자
1. **협력기업 기술팀** — 적용 가능 기술 탐색
2. **내부 연구원** — 연구 방향 참고
3. **학생/인턴** — 트렌드 학습
4. **산업계 일반** — 동서대 연구소 인지도 제고

### 3.2 인사이트 프레임워크

각 SOTA 항목에 대해 다음 분석 수행:

#### 3.2.1 산업 매핑
| 산업군 | 세부 분야 |
|--------|----------|
| **영상 제작** | 실사 영화, 애니메이션, 광고, 뮤직비디오 |
| **게임** | AAA, 인디, 모바일, VR/AR |
| **방송** | 뉴스, 예능, 스포츠, 버추얼 |
| **교육** | 이러닝, 시뮬레이션, 메타버스 |
| **건축/설계** | 시각화, BIM, 인테리어 |

#### 3.2.2 파이프라인 매핑
```
[프리프로덕션]
  └─ 기획 → 스토리보드 → 콘셉트아트 → 프리비즈

[프로덕션]
  └─ 모델링 → 리깅 → 애니메이션 → 텍스처링 → 라이팅 → 렌더링

[포스트프로덕션]
  └─ 합성 → 색보정 → VFX → 사운드 → 최종출력
```

#### 3.2.3 실증 가능성 판단
| 등급 | 조건 | 액션 |
|------|------|------|
| ✅ 즉시 실증 | GitHub 코드 + 문서화 + 일반 GPU | 이번 주 테스트 |
| 🔧 커스텀 필요 | 코드 있으나 수정 필요 | 연구원 검토 후 |
| 💻 고사양 필요 | H100/A100 필요 | H100 서버 활용 |
| ❌ 코드 미공개 | 논문만 | Watch & Wait |
| 🔒 상용 라이선스 | 유료/기업용 | 라이선스 검토 |

## 4. 기술 스택

### 4.1 수집/분석 (Backend)
| 구성요소 | 기술 | 비고 |
|----------|------|------|
| 수집기 | Python (기존 extractors.py 확장) | arXiv, HF, Reddit, GitHub |
| 분석 엔진 | 아르카 (Claude) | 인사이트 생성 |
| 저장소 | Notion Database | 작업 데이터 |
| 스케줄러 | OpenClaw Cron | 자동 수집/생성 |

### 4.2 리포트 생성 (Generator)
| 구성요소 | 기술 | 비고 |
|----------|------|------|
| 템플릿 엔진 | Jinja2 / Markdown | 리포트 포맷 |
| 변환기 | Pandoc / Next.js | MD → HTML |
| 스타일 | TailwindCSS | 깔끔한 디자인 |

### 4.3 웹 호스팅 (Frontend)
| 옵션 | 장점 | 단점 | 추천 |
|------|------|------|------|
| **Vercel** | 무료, 빠름, Next.js 최적화 | - | ⭐ 추천 |
| GitHub Pages | 무료, 간단 | 빌드 제한 | 백업 옵션 |
| Cloudflare Pages | 무료, 빠름 | 설정 복잡 | - |
| Notion Public | 가장 간단 | 커스텀 제한 | MVP용 |

### 4.4 배포 (Distribution)
| 채널 | 방법 |
|------|------|
| 웹사이트 | sota.dsu-xr.kr (커스텀 도메인) |
| 이메일 | Resend / SendGrid (무료 티어) |
| 텔레그램 | 채널 자동 포스팅 |
