## 1. 프로젝트 개요

### 1.1 목적
AI/3D/영상 분야 최신 연구(SOTA)를 **수집 → 검토 → 실증 → 리포트**하는 체계적 파이프라인 구축

### 1.2 문제 정의
현재 상황:
- SOTA 정보가 흩어져 있음 (Reddit, HuggingFace, arXiv, YouTube 등)
- 수집만 하고 실제 검증/적용까지 안 감
- "봤는지", "테스트해봤는지" 추적 안 됨
- 코드 공개 여부 파악 어려움

### 1.3 목표
1. **통합 수집**: 다양한 소스에서 SOTA 자동 수집
2. **상태 추적**: 신규 → 검토 → 실증 → 완료 상태 관리
3. **실증 가능성 판단**: 코드 공개 여부, 하드웨어 요구사항 자동 체크
4. **협업 지원**: 연구자 할당, 리포트 작성

## 3. 사용자 시나리오

### 시나리오 1: Reddit 글 수집
```
1. 준석이 텔레그램에 Reddit URL 던짐
2. 아르카가 본문 파싱 + 내부 링크들 추출
3. 각 링크 분석 (arXiv면 논문, GitHub면 코드 체크)
4. 한국어 요약 생성
5. 실증가능성 판단 (코드 있으면 "실증요망")
6. 노션에 저장 → 준석에게 요약 보고
```

### 시나리오 2: HuggingFace 트렌딩 체크 (자동)
```
1. 하트비트에서 HF Daily Papers 체크 (하루 1-2회)
2. 준석 관심 분야 필터링
3. 관련성 높은 것만 노션에 저장
4. 중요한 거 있으면 준석에게 알림
```

### 시나리오 3: 실증 후 리포트
```
1. 연구자가 노션에서 "실증요망" 항목 확인
2. 담당자로 본인 할당
3. 테스트 진행
4. 실증노트에 결과 작성 (성공/실패, 적용 가능 여부)
5. 상태 → "실증완료"
```

## 5. 노션 데이터베이스 스키마 (확정안)

| 속성 | 타입 | 설명 | 옵션 |
|------|------|------|------|
| **이름** | title | 제목 | - |
| **URL** | url | 원본 링크 | - |
| **요약** | text | 한국어 요약 (아르카 작성) | - |
| **카테고리** | select | 분야 | AI생성 / 3D재구성 / 에이전트 / 영상 / 오디오 / 워크플로우 |
| **관련성** | select | 준석 기준 관련성 | 🔥핵심 / ⭐관심 / 📌참고 |
| **실증가능성** | select | 테스트 가능 여부 | ✅바로가능 / 🔧커스텀필요 / ❌코드미공개 / 💻GPU필요 |
| **상태** | select | 진행 상태 | 🆕신규 / 👀검토중 / 🔬실증요망 / ✅실증완료 / ⏸️보류 |
| **담당자** | select | 실증 담당 | 준석 / 연구원A / 연구원B / 아르카 |
| **실증노트** | text | 테스트 결과 | - |
| **날짜** | date | 수집일 | - |
| **관련링크** | text | 추가 링크들 | - |
| **태그** | multi_select | 자유 태그 | ComfyUI / Flux / 3DGS / ... |
