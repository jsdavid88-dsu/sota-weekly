1. 🔥 [에이전트] 이종 에이전트 협력 강화학습 (HACRL)

  • 원제: Heterogeneous Agent Collaborative Reinforcement Learning
  • Upvotes: 136
  • 링크: https://huggingface.co/papers/2603.02604
  • 한줄 요약: 서로 다른 구조의 에이전트들이 학습 시에는 검증된 롤아웃을 공유해 상호 개선하고, 추론 시에는 독립 실행하는 새로운 협력 강화학습 패러다임.
  • 상세: 기존 온-폴리시 최적화의 비효율을 해결. LLM 기반 MARL처럼 배포 단계에서 조율이 필요 없고, 오프-폴리시처럼 분포 불일치 문제도 없음. 이종 에이전트 간 롤아웃 공유로 샘플 효율 극대화.

2. ⭐ [영상] Helios: 실시간 장편 영상 생성 모델

  • 원제: Helios: Real Real-Time Long Video Generation Model
  • Upvotes: 127
  • 링크: https://huggingface.co/papers/2603.04379
  • 한줄 요약: H100 단일 GPU에서 19.5 FPS로 분 단위 장편 영상을 실시간 생성하는 14B 파라미터 모델.
  • 상세: 셀프-포싱·KV-캐시·스파스 어텐션 등 일반적 기법 없이도 긴 영상 드리프트 없이 안정적 생성. 실시간 + 장편 동시 달성이라는 두 마리 토끼를 잡은 첫 사례.

3. ⭐ [AI생성] T2S-Bench & 사고 구조화(SoT): 텍스트→구조 추론 벤치마크

  • 원제: T2S-Bench & Structure-of-Thought: Benchmarking and Prompting Comprehensive Text-to-Structure Reasoning
  • Upvotes: 105
  • 링크: https://huggingface.co/papers/2603.03790
  • 한줄 요약: LLM이 복잡한 텍스트를 처리할 때 중간 구조(텍스트 트리, 그래프 등)를 명시적으로 구성하도록 유도하는 프롬프팅 기법 + 종합 벤치마크 제안.
  • 상세: 8개 과제에서 일관되게 성능 향상. 사람이 글을 읽을 때 핵심 포인트를 표시하고 관계를 추론하는 방식을 LLM에 적용.

4. ⭐ [AI생성] MOOSE-Star: 과학적 발견을 위한 효율적 LLM 학습

  • 원제: MOOSE-Star: Unlocking Tractable Training for Scientific Discovery by Breaking the Complexity Barrier
  • Upvotes: 74
  • 링크: https://huggingface.co/papers/2603.03756
  • 한줄 요약: 방대한 지식 베이스에서 영감을 조합해 가설을 생성하는 P(h|b) 학습의 조합론적 복잡도(O(N^k))를 극복하는 새로운 프레임워크.
  • 상세: 과학적 발견 과정의 생성적 추론을 직접 모델링하는 첫 시도. 추론 단계나 피드백 기반 학습에 집중하던 기존 연구의 공백을 메움.

  • Upvotes: 43
  • 링크: https://huggingface.co/papers/2603.04448

  • 상세: 현재 에이전트들은 각 맥락에서 해결책을 독립적으로 재발견하는 비효율이 있음. SkillNet은 스킬 생성·평가·연결을 통합 관리해 장기적 에이전트 발전을 지원.

  • 원제: DARE: Aligning LLM Agents with the R Statistical Ecosystem via Distribution-Aware Retrieval
  • Upvotes: 41
  • 링크: https://huggingface.co/papers/2603.04743
  • 한줄 요약: 함수 의미론만이 아닌 데이터 분포 정보까지 반영하는 검색 임베딩으로 LLM의 R 통계 도구 선택 정확도 향상.
  • 상세: 기존 RAG는 함수 레벨 시맨틱만 보고 데이터 분포를 무시해 차선의 매칭 결과를 냄. DARE는 경량 플러그-앤-플레이 방식으로 R 생태계 통계 방법 활용도를 높임.

  • Upvotes: 28

  • 상세: 기존 벤치마크는 단일 턴 시각 추론이나 특정 도구 스킬만 평가. AgentVista는 현실감·시각적 미묘함·장기 계획 능력을 통합 평가.
