3 🤖에이전트 EnterpriseOps-Gym: 기업 환경의 상태 유지형 에이전트 계획 및 도구 사용 평가 116 기업 IT 운영 시나리오에서 에이전트의 장기 상태 관리·도구 활용 능력을 평가하는 벤치마크
4 🧊3D재구성 HSImul3R: 시뮬레이션용 인간-장면 상호작용의 물리 기반 재구성 92 물리 시뮬레이션이 가능한 수준의 인간-환경 상호작용 3D 재구성 파이프라인
5 🎬영상 실제 대도시를 기반으로 한 월드 시뮬레이션 모델의 그라운딩 92 실제 도시 환경 데이터로 월드 시뮬레이션 모델을 현실에 고정(grounding)하는 방법론
6 🎨AI생성 Attention Residuals: 어텐션 잔차 57 트랜스포머 어텐션에 잔차 연결을 도입하여 학습 안정성·성능 동시 향상
7 🎨AI생성 Mixture-of-Depths Attention: 깊이 혼합 어텐션 48 토큰별로 어텐션 깊이를 동적 할당하여 계산 효율성과 성능을 동시에 확보
8 🎨AI생성 하이브리드 xLSTM 아키텍처로의 효과적 증류 30 트랜스포머 지식을 xLSTM 하이브리드 구조로 효율적으로 증류하는 기법
9 🎨AI생성 거짓말의 해부학: 비전-언어 모델 환각 추적을 위한 다단계 진단 프레임워크 24 VLM이 환각을 생성하는 내부 과정을 단계별로 추적·진단하는 해석 가능 프레임워크
10 🧊3D재구성 ViFeEdit: 비디오 없이 비디오 확산 트랜스포머를 튜닝하기 21 비디오 데이터 없이 이미지만으로 비디오 확산 모델을 미세조정하는 편집 기법

🔍 주요 논문 상세

1. AI는 과학적 안목을 학습할 수 있다 (AI Can Learn Scientific Taste)

  • 카테고리: AI생성 | Upvotes: 214
  • AI가 단순 키워드 매칭이 아닌 과학적 '안목'(taste) — 논문의 참신성, 영향력, 방법론적 엄밀함을 사전 판별하는 능력을 학습할 수 있음을 실증. 논문 스크리닝·리뷰 자동화에 큰 시사점.

2. OpenSeeker: 프론티어 검색 에이전트 민주화 (OpenSeeker)

  • 카테고리: 에이전트 | Upvotes: 124
  • Perplexity·SearchGPT 같은 검색 에이전트의 훈련 데이터·기법을 완전 공개. 데이터 수집→정제→학습 전 과정을 재현 가능하게 만들어 오픈소스 검색 에이전트 생태계 구축.

3. EnterpriseOps-Gym: 기업 운영 에이전트 평가 환경 (EnterpriseOps-Gym)

  • 카테고리: 에이전트 | Upvotes: 116
  • 클라우드 인프라 관리, IT 장애 대응 등 기업 운영 시나리오에서 AI 에이전트의 상태 유지형 계획 수립과 도구 사용 능력을 체계적으로 평가하는 벤치마크.

4. HSImul3R: 물리 시뮬레이션용 인간-장면 상호작용 재구성 (HSImul3R)

  • 카테고리: 3D재구성 | Upvotes: 92
  • 3D 스캔에서 물리 엔진에서 바로 사용할 수 있는 수준의 인간-환경 상호작용 데이터를 재구성. 물리 법칙을 루프에 포함시켜 관통·부유 없는 사실적 결과 생성. 준석 연구 직결: 3D Reconstruction + UE5 파이프라인에 직접 연관.

5. 실제 대도시 기반 월드 시뮬레이션 그라운딩 (Grounding World Simulation Models)

  • 카테고리: 영상 | Upvotes: 92
  • 합성 데이터가 아닌 실제 대도시(메트로폴리스) 환경에서 월드 모델을 그라운딩. 도시 규모 시뮬레이션의 현실성을 크게 향상. 준석 연구 관련: 부산 로케이션 기반 VFX·가상환경 구축에 참고 가능.

6. Attention Residuals: 어텐션 잔차 (Attention Residuals)

  • 카테고리: AI생성 | Upvotes: 57
  • 기존 어텐션 메커니즘에 잔차(residual) 경로를 추가하여 그래디언트 흐름 개선. 심층 트랜스포머의 학습 안정성과 최종 성능 모두 향상.

7. Mixture-of-Depths Attention: 깊이 혼합 어텐션 (MoD-Attention)

  • 카테고리: AI생성 | Upvotes: 48
  • Mixture-of-Experts의 아이디어를 '깊이' 차원에 적용. 각 토큰이 필요한 만큼만 어텐션 레이어를 통과하도록 라우팅하여, 품질 유지하면서 추론 비용 절감.

8. 하이브리드 xLSTM으로의 효과적 증류 (Effective Distillation to Hybrid xLSTM)

  • 카테고리: AI생성 | Upvotes: 30
  • 대형 트랜스포머의 지식을 xLSTM 기반 하이브리드 아키텍처로 증류. 선형 시간 복잡도의 장점을 유지하면서 트랜스포머급 성능 달성.

9. 거짓말의 해부학: VLM 환각 추적 진단 (Anatomy of a Lie)

  • 카테고리: AI생성 | Upvotes: 24
  • 비전-언어 모델이 환각을 생성하는 과정을 다단계로 분해 분석. 시각 인코딩→크로스 어텐션→디코딩 각 단계에서 환각 원인을 특정하여 타겟 교정 가능.

10. ViFeEdit: 비디오 없이 비디오 모델 튜닝 (ViFeEdit)

  • 카테고리: 3D재구성 | Upvotes: 21
  • 비디오 확산 트랜스포머를 이미지 데이터만으로 미세조정하는 혁신적 접근. 비디오 데이터 수집 비용 없이 편집 능력 부여. 준석 연구 관련: ComfyUI 비디오 워크플로우에 활용 잠재력.
