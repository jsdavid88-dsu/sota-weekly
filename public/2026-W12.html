# 카테고리 한글 제목 ⬆️ 한줄 요약
1 🎬영상 비전-언어 모델이 야바위를 풀 수 있을까? 26 VLM의 시각적 추적·공간 추론 능력을 야바위(셸 게임)로 벤치마킹하는 새 평가 프레임워크
2 🎨AI생성 Cheers: 패치 디테일과 의미 표현 분리로 통합 멀티모달 이해·생성 달성 26 패치 수준 디테일과 고수준 의미를 분리해 이미지 이해와 생성을 단일 모델로 통합
3 🤖에이전트 XSkill: 멀티모달 에이전트의 경험·스킬 기반 지속 학습 24 파라미터 업데이트 없이 과거 궤적에서 경험(도구 선택 가이드)과 스킬(재사용 가능 서브루틴)을 학습하는 프레임워크
4 🤖에이전트 daVinci-Env: 대규모 오픈 SWE 환경 합성 20 소프트웨어 엔지니어링 에이전트 훈련용 실행 환경을 자동 합성하는 오픈소스 파이프라인 🔥
5 🎬영상 OmniForcing: 실시간 동시 오디오-비주얼 생성 19 오디오와 영상을 동시에 실시간으로 생성하는 통합 프레임워크
6 🎬영상 DVD: 생성 사전지식 기반 결정론적 비디오 깊이 추정 19 확산 모델을 단일 패스 깊이 회귀기로 결정론적 변환 — 확률적 환각·스케일 드리프트 해결
7 🧊3D재구성 멀티모달 OCR: 문서에서 모든 것을 파싱하다 16 이종 문서(표·수식·차트·혼합 레이아웃)를 통합 처리하는 멀티모달 OCR 파이프라인
8 🤖에이전트 MM-CondChain: 시각 기반 심층 구성적 추론 벤치마크 16 프로그램으로 검증 가능한 조건 체인형 시각-언어 추론 벤치마크
9 🎨AI생성 Visual-ERM: 시각적 동등성을 위한 보상 모델링 16 이미지 편집·생성에서 "의미적으로 동등한가"를 판단하는 보상 모델 — RL 파이프라인 강화
10 🎨AI생성 CREATE: LLM의 연상적 창의성 테스트 13 인간 심리학의 연상 창의성 과제를 LLM에 적용한 새 벤치마크

🔍 주요 논문 상세

1. 비전-언어 모델이 야바위를 풀 수 있을까? (Can VLMs Solve the Shell Game?)

  • 카테고리: 영상 | Upvotes: 26
  • VLM이 시각적 물체 추적과 공간 추론을 동시에 수행할 수 있는지 야바위(셸 게임) 시나리오로 테스트. 현재 최고 모델도 복잡한 추적에서 크게 실패하며, 시각 추론 한계를 정량적으로 드러냄.

2. Cheers: 패치 디테일-의미 표현 분리 통합 멀티모달 모델

  • 카테고리: AI생성 | Upvotes: 26
  • 기존 멀티모달 모델의 "이해 vs 생성" 트레이드오프를 해결. 이미지 패치의 저수준 디테일과 고수준 의미를 명시적으로 분리해 한 모델이 이해·생성 모두 고품질 수행.

3. XSkill: 멀티모달 에이전트 지속 학습

  • 카테고리: 에이전트 | Upvotes: 24
  • 에이전트가 과거 작업 이력에서 (1) 도구 선택 가이드라인(경험), (2) 재사용 가능한 실행 패턴(스킬)을 자동 추출. 가중치 업데이트 없이 지속적으로 개선.

4. daVinci-Env: 대규모 오픈 SWE 환경 합성 🔥

  • 카테고리: 에이전트 | Upvotes: 20
  • SWE-bench 류 평가의 핵심 병목(실행 환경 구축)을 자동화. 리포지토리에서 빌드·테스트 환경을 자동 합성해 에이전트 훈련 데이터 대규모 생산.

5. OmniForcing: 실시간 동시 오디오-비주얼 생성

  • 카테고리: 영상 | Upvotes: 19
  • 오디오와 영상을 별도 생성 후 후처리하던 기존 방식 대신, 실시간 동시 생성으로 시청각 일관성 확보. 라이브 콘텐츠 파이프라인에 직접 응용 가능.

6. DVD: 결정론적 비디오 깊이 추정

  • 카테고리: 영상 | Upvotes: 19
  • 사전학습된 비디오 확산 모델을 단일 패스 깊이 추정기로 변환. 확률적 샘플링의 불안정성(환각, 스케일 드리프트) 제거. 준석 연구 관련: 3D 재구성·VFX 파이프라인에 직접 활용 가능.

7. 멀티모달 OCR: 문서 만능 파서

  • 카테고리: 3D재구성 | Upvotes: 16
  • 표, 수식, 차트, 혼합 레이아웃 등 이종 문서 요소를 통합 처리. 기존 OCR의 "한 종류만 잘함" 한계를 넘어 범용 문서 파싱 달성.

8. MM-CondChain: 시각 기반 구성적 추론 벤치마크

  • 카테고리: 에이전트 | Upvotes: 16
  • "A이면 B이고, B이면 C" 같은 조건 체인 추론을 시각 입력과 결합. 프로그램으로 자동 검증 가능해 대규모 평가에 적합.

9. Visual-ERM: 시각적 동등성 보상 모델링

  • 카테고리: AI생성 | Upvotes: 16
  • 이미지 편집 결과가 "의도대로 바뀌었는가"를 판단하는 보상 모델. RL 기반 이미지 편집·생성 파이프라인의 학습 안정성 향상.

10. CREATE: LLM 연상 창의성 벤치마크

  • 카테고리: AI생성 | Upvotes: 13
  • 인간 창의성 심리학 테스트(RAT 등)를 LLM에 적용. 단순 지식 검색이 아닌 "연상적 도약" 능력을 측정하는 새 프레임워크.
