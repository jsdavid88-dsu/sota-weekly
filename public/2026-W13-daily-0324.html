🏆 Top 10 논문 (Upvotes 순)

1. [영상] HopChain: 일반화 가능한 비전-언어 추론을 위한 다중 홉 데이터 합성

  • 원제: HopChain: Multi-Hop Data Synthesis for Generalizable Vision-Language Reasoning
  • Upvotes: 94 ⭐
  • 한줄 요약: 비전-언어 모델의 복잡한 다단계 추론 능력을 강화하기 위해 다중 홉(multi-hop) 합성 데이터를 자동 생성하는 프레임워크. 단순 단일 질문 응답을 넘어 연쇄적 시각 추론을 학습시킴.

2. [영상] Astrolabe: 증류된 자기회귀 영상 모델을 위한 순방향 프로세스 강화학습 조향

  • 원제: Astrolabe: Steering Forward-Process Reinforcement Learning for Distilled Autoregressive Video Models
  • Upvotes: 83 ⭐
  • 한줄 요약: 증류(distilled) 영상 생성 모델의 품질을 순방향 프로세스 RL로 미세 조정하여, 추론 비용 없이 생성 영상의 시각적 품질과 시간 일관성을 대폭 향상시키는 방법.

3. [3D재구성] 3DreamBooth: 고충실도 3D 주체 기반 영상 생성 모델

  • 원제: 3DreamBooth: High-Fidelity 3D Subject-Driven Video Generation Model
  • Upvotes: 53 ⭐
  • 한줄 요약: 2D 이미지 기반의 기존 주체 커스터마이징을 넘어, 3D 공간 사전지식을 1프레임 최적화로 주입하여 다시점에서도 정체성이 보존되는 영상 생성 프레임워크. VR/AR·가상 프로덕션에 직결.

4. [3D재구성] MonoArt: 단안 관절형 3D 재구성을 위한 점진적 구조 추론

  • 원제: MonoArt: Progressive Structural Reasoning for Monocular Articulated 3D Reconstruction
  • Upvotes: 35 ⭐
  • 한줄 요약: 단일 이미지에서 관절형(articulated) 3D 객체의 기하·파트 구조·모션을 통합 추론하는 프레임워크. 외부 모션 템플릿 없이 점진적 구조 추론으로 SOTA 달성. 로봇 조작에도 확장 가능.

5. [AI생성] ProactiveBench: 멀티모달 대형 언어 모델의 능동성 벤치마크

  • 원제: ProactiveBench: Benchmarking Proactiveness in Multimodal Large Language Models
  • Upvotes: 26 ⭐
  • 한줄 요약: MLLM이 사용자의 요청을 기다리지 않고 스스로 정보를 파악하고 제안하는 '능동성(proactiveness)'을 체계적으로 평가하는 최초의 벤치마크.

6. [AI생성] FlowScene: 멀티모달 그래프 정류 흐름 기반 스타일 일관 실내 장면 생성

  • 원제: FlowScene: Style-Consistent Indoor Scene Generation with Multimodal Graph Rectified Flow
  • Upvotes: 24 ⭐
  • 한줄 요약: 실내 장면 전체를 스타일 일관성 있게 생성하기 위해, 멀티모달 그래프 구조와 정류 흐름(Rectified Flow)을 결합한 생성 파이프라인. 인테리어 디자인·건축 시각화에 활용 가능.

7. [영상] ReactMotion: 화자 발화에서 반응형 청취자 모션 생성

  • 원제: ReactMotion: Generating Reactive Listener Motions from Speaker Utterance
  • Upvotes: 24 ⭐
  • 한줄 요약: 대화 중 화자의 발화에 맞춰 청취자가 자연스럽게 반응하는 모션(고개 끄덕임, 표정 변화 등)을 자동 생성하는 모델. 가상 아바타·디지털 휴먼 대화 시스템에 핵심.

8. [에이전트] AndroTMem: 장기 GUI 에이전트를 위한 인터랙션 궤적 기반 앵커드 메모리

  • 원제: AndroTMem: From Interaction Trajectories to Anchored Memory in Long-Horizon GUI Agents
  • Upvotes: 23 ⭐
  • 한줄 요약: 안드로이드 GUI 에이전트가 긴 작업 시퀀스에서 과거 인터랙션 궤적을 구조화된 앵커 메모리로 변환하여, 장기 맥락을 잃지 않고 복잡한 다단계 작업을 수행하는 방법.

9. [AI생성] LLM을 위한 Y-컴비네이터: 미적분학으로 장문맥 부패 해결

  • 원제: The Y-Combinator for LLMs: Solving Long-Context Rot with Calculus
  • Upvotes: 21 ⭐
  • 한줄 요약: LLM의 장문맥(long-context) 처리 시 발생하는 성능 저하(rot)를 수학적 미적분 기법으로 해결하는 이론적 프레임워크. 컨텍스트 윈도우 확장의 근본적 한계를 공략.

10. [에이전트] LumosX: 개인화 영상 생성을 위한 정체성-속성 관계 매핑

  • 원제: LumosX: Relate Any Identities with Their Attributes for Personalized Video Generation
  • Upvotes: 21 ⭐
  • 한줄 요약: 다수의 인물 정체성과 각각의 속성(외모·동작·스타일)을 유연하게 매핑하여, 개인화된 멀티 캐릭터 영상을 생성하는 시스템.
