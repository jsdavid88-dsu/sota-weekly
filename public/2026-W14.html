📊 이번 주 논문 요약

# 카테고리 한글 제목 Upvotes 한줄 요약
1 에이전트 ClawKeeper: 스킬·플러그인·감시자를 통한 OpenClaw 에이전트의 포괄적 안전 보호 166 OpenClaw 에이전트 생태계의 안전성을 스킬/플러그인/감시자 삼중 구조로 보장하는 프레임워크 제안
2 에이전트 터미널 에이전트만으로 충분하다: 기업 자동화를 위한 접근 68 GUI 기반 에이전트 없이 터미널 에이전트만으로 기업 업무 자동화가 가능함을 입증
3 AI생성 Project Imaging-X: 파운데이션 모델 개발을 위한 1,000+개 공개 의료 영상 데이터셋 서베이 53 의료 AI 파운데이션 모델 훈련에 활용 가능한 1,000개 이상의 오픈 의료영상 데이터셋을 체계적으로 정리
4 에이전트 MiroEval: 멀티모달 심층 연구 에이전트의 과정과 결과 벤치마킹 52 멀티모달 딥리서치 에이전트의 추론 과정과 최종 결과를 동시에 평가하는 새로운 벤치마크
5 영상 ViGoR-Bench: 시각 생성 모델은 제로샷 시각 추론에서 얼마나 멀리 있는가 36 시각 생성 모델의 제로샷 시각적 추론 능력을 체계적으로 평가하는 벤치마크 제안
6 에이전트 Vision2Web: 에이전트 검증 기반 시각적 웹사이트 개발 계층적 벤치마크 32 시각 디자인→웹사이트 구현 과정을 에이전트가 검증하는 계층적 벤치마크
7 에이전트 추론 전환: 컨텍스트가 어떻게 LLM 추론을 조용히 단축시키는가 22 입력 컨텍스트가 길어질수록 LLM의 추론 체인이 무의식적으로 짧아지는 현상 분석
8 에이전트 HippoCamp: 개인 컴퓨터 환경에서의 컨텍스트 에이전트 벤치마킹 16 개인 PC 환경에서 에이전트가 사용자 맥락을 이해하고 작업하는 능력을 평가하는 벤치마크
9 에이전트 Dynin-Omni: 옴니모달 통합 대규모 확산-언어 모델 15 텍스트·이미지·오디오를 하나의 확산-언어 모델로 통합 생성하는 옴니모달 아키텍처
10 영상 PerceptionComp: 복잡한 지각 중심 추론을 위한 비디오 벤치마크 14 비디오 이해에서 복잡한 지각적 추론 능력을 측정하는 새로운 벤치마크

🔥 주요 트렌드

  • 에이전트 안전성·벤치마킹 주도: 10편 중 7편이 에이전트 관련. 특히 안전 보호(ClawKeeper)와 다양한 벤치마크(MiroEval, HippoCamp, Vision2Web)가 눈에 띔
  • 터미널 에이전트의 부상: GUI 없이 CLI만으로 기업 자동화를 달성하는 방향성 주목
  • 추론 체인 단축 문제: 컨텍스트 길이가 추론 품질에 미치는 영향 — 실무적으로 중요한 발견
  • 영상/비전 벤치마크: 생성 모델의 추론 능력과 비디오 이해력 평가 도구 등장
