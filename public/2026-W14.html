2 🤖 에이전트 Intern-S1-Pro: 조 단위 파라미터의 과학 멀티모달 파운데이션 모델 117 1조 파라미터 규모의 최초 과학 특화 멀티모달 모델, 100개+ 과학 분야 태스크 마스터
3 🎨 AI생성 PixelSmile: 세밀한 얼굴 표정 편집을 향하여 114 연속적 감정 주석 데이터셋(FFE)과 디퓨전 기반 표정 의미 분리 프레임워크 제안
4 🎬 영상 ShotStream: 인터랙티브 스토리텔링을 위한 스트리밍 멀티샷 비디오 생성 110 실시간 스트리밍 방식으로 멀티샷 비디오를 생성, 인터랙티브 스토리텔링 지원
5 🎨 AI생성 Calibri: 파라미터 효율적 캘리브레이션으로 디퓨전 트랜스포머 강화 60 DiT 블록에 단일 학습 스케일링 파라미터만 추가해 생성 품질을 크게 향상
6 🎨 AI생성 RealRestorer: 대규모 이미지 편집 모델을 활용한 범용 실세계 이미지 복원 50 대규모 편집 모델의 일반화 능력을 활용해 실세계 열화 이미지를 고품질 복원
7 🔊 오디오 Voxtral TTS 49 3초 레퍼런스 오디오만으로 자연스러운 다국어 음성을 생성하는 하이브리드 TTS 모델
8 🤖 에이전트 MSA: 1억 토큰까지 확장 가능한 효율적 엔드투엔드 메모리 모델용 희소 어텐션 39 풀 어텐션의 1M 토큰 한계를 넘어 100M 토큰까지 확장하는 메모리 희소 어텐션
9 🧊 3D재구성 PackForcing: 짧은 비디오 학습만으로 긴 비디오 샘플링과 장문맥 추론 달성 38 짧은 비디오 데이터로 학습해도 긴 비디오 생성과 장문맥 추론이 가능함을 입증
10 🤖 에이전트 Trace2Skill: 궤적-국소 교훈을 전이 가능한 에이전트 스킬로 증류 33 에이전트 실행 궤적에서 재사용 가능한 스킬을 자동 추출하는 증류 방법론

📝 상세 요약

1. Out of Sight but Not Out of Mind ⬆️133

카테고리: 영상 | 키워드: Video World Model, Hybrid Memory, Object Persistence

비디오 월드 모델에서 카메라 밖으로 사라진 객체를 지속적으로 추적하는 하이브리드 메모리 메커니즘을 제안한다. 기존 모델들은 시야에서 벗어난 객체를 즉시 "잊어버리는" 문제가 있었는데, 이 연구는 명시적 메모리와 암묵적 메모리를 결합해 동적 장면에서도 일관된 세계 상태를 유지한다.

💡 준석 관심 포인트: 부산마법소녀 긴 시퀀스 생성 시 객체 일관성 유지에 직접 적용 가능

2. Intern-S1-Pro ⬆️117

카테고리: 에이전트 | 키워드: Trillion-Scale, Scientific AI, Multimodal

최초의 1조 파라미터 과학 특화 멀티모달 모델. 범용 추론·이미지-텍스트 이해뿐 아니라 100개 이상의 과학 분야 전문 태스크를 수행한다. 에이전트 기능도 내장되어 과학 연구 자동화 파이프라인에 활용 가능.

3. PixelSmile ⬆️114

카테고리: AI생성 | 키워드: Facial Expression, Diffusion, Fine-grained Editing

얼굴 표정 편집에서 의미적 중첩(예: '놀람'과 '공포'의 혼동) 문제를 해결. 연속적 감정 주석이 달린 FFE 데이터셋을 구축하고, 완전 대칭 공동 훈련으로 표정 의미를 분리하는 디퓨전 프레임워크 PixelSmile을 제안.

💡 준석 관심 포인트: ComfyUI 캐릭터 표정 제어 파이프라인에 핵심 기술

4. ShotStream ⬆️110

카테고리: 영상 | 키워드: Multi-Shot Generation, Streaming, Interactive Storytelling

멀티샷 비디오를 스트리밍 방식으로 생성해 사용자가 실시간으로 스토리 전개에 개입할 수 있는 시스템. 기존의 일괄 생성 방식 대비 인터랙티브 내러티브 경험을 제공한다.

💡 준석 관심 포인트: 부산마법소녀 IP의 인터랙티브 콘텐츠 프로토타이핑에 유망

5. Calibri ⬆️60

카테고리: AI생성 | 키워드: DiT, Parameter-Efficient, Calibration

Diffusion Transformer(DiT) 블록에 단 하나의 학습 가능한 스케일링 파라미터를 추가하는 것만으로 생성 품질이 크게 향상됨을 발견. 블랙박스 보상 최적화로 DiT 컴포넌트를 캘리브레이션하는 경량 접근법 Calibri를 제안.

6. RealRestorer ⬆️50

카테고리: AI생성 | 키워드: Image Restoration, Real-world Degradation, Editing Model

기존 복원 모델의 학습 데이터 분포 한계를 대규모 이미지 편집 모델의 일반화 능력으로 극복. 자율주행, 객체 탐지 등 다운스트림 태스크에 중요한 실세계 이미지 복원에서 범용 성능을 달성.

7. Voxtral TTS ⬆️49

카테고리: 오디오 | 키워드: TTS, Multilingual, Few-shot Voice Cloning

3초의 레퍼런스 오디오만으로 자연스러운 음성을 합성하는 다국어 TTS. 의미적 토큰의 자기회귀 생성과 음향 토큰의 플로우 매칭을 결합한 하이브리드 아키텍처. 자체 개발한 VQ-FSQ 기반 Voxtral Codec 사용.

8. MSA: Memory Sparse Attention ⬆️39

카테고리: 에이전트 | 키워드: Long Context, 100M Tokens, Sparse Attention

LLM의 실질적 컨텍스트 길이를 1M에서 100M 토큰까지 확장하는 메모리 희소 어텐션 메커니즘. 하이브리드 선형 어텐션, RNN, RAG 등 기존 접근법의 한계를 극복하는 엔드투엔드 방식.

9. PackForcing ⬆️38

카테고리: 3D재구성 | 키워드: Long Video Generation, Short Training, Context Inference

짧은 비디오 클립으로만 학습해도 긴 비디오 샘플링과 장문맥 추론이 가능함을 보인 연구. 학습 데이터 길이와 생성 가능 길이 사이의 갭을 PackForcing 기법으로 해소.

10. Trace2Skill ⬆️33

카테고리: 에이전트 | 키워드: Skill Distillation, Trajectory Learning, Transfer

에이전트의 실행 궤적(trajectory)에서 국소적 교훈을 추출하고, 이를 다른 태스크에 전이 가능한 재사용 스킬로 증류하는 방법론. 에이전트의 경험 축적과 스킬 라이브러리 구축을 자동화.
