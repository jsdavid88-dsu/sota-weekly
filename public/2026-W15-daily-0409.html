1. [영상] Video-MME-v2: 포괄적 비디오 이해 벤치마크의 다음 단계로

  • 원제: Video-MME-v2: Towards the Next Stage in Benchmarks for Comprehensive Video Understanding
  • Upvotes: 197
  • 한줄 요약: 리더보드 점수는 높지만 실제 비디오 이해력은 부족한 문제를 겨냥해, 더 어려운 계층형 평가 체계를 갖춘 차세대 비디오 이해 벤치마크를 제안한다.
  • 요약 번역: 기존 비디오 이해 벤치마크는 점점 포화 상태에 이르며, 높은 점수와 실제 모델 능력 사이의 괴리가 커지고 있다. Video-MME-v2는 이런 간극을 줄이기 위해 견고성과 충실성을 더 엄격하게 측정하는 종합 벤치마크다. 모델 역량을 체계적으로 평가하기 위해 난이도가 점진적으로 높아지는 3단계 계층 구조를 설계했다.
  • 링크: https://huggingface.co/papers/2604.05015

2. [에이전트] Adam의 법칙: 대형 언어모델에서의 텍스트 빈도 법칙

  • 원제: Adam's Law: Textual Frequency Law on Large Language Models
  • Upvotes: 158
  • 한줄 요약: 사람의 읽기 인지에서 중요하다고 알려진 텍스트 빈도 효과가 LLM에도 적용되며, 자주 등장하는 표현을 선호할수록 프롬프팅과 파인튜닝 성능이 좋아진다고 주장한다.
  • 요약 번역: 텍스트 빈도는 인간의 읽기 속도와 인지에서 유의미한 요소로 알려져 있지만, LLM과의 관계는 거의 연구되지 않았다. 이 논문은 텍스트 데이터 빈도라는 새로운 연구 방향을 제안하며, 빈도가 높은 텍스트 표현이 프롬프팅과 파인튜닝 모두에서 더 유리하다는 텍스트 빈도 법칙(TFL)을 제시한다.
  • 링크: https://huggingface.co/papers/2604.02176

3. [에이전트] Claw-Eval: 신뢰할 수 있는 자율 에이전트 평가를 향하여

  • 원제: Claw-Eval: Toward Trustworthy Evaluation of Autonomous Agents
  • Upvotes: 95
  • 한줄 요약: 최종 결과만 채점하는 기존 벤치마크의 한계를 넘어, trajectory·안전성·멀티모달 상호작용까지 포함한 종단형 에이전트 평가 스위트를 제안한다.
  • 요약 번역: LLM 기반 자율 에이전트는 실제 소프트웨어 환경에서 다단계 작업을 수행하고 있지만, 기존 벤치마크는 최종 출력만 보고 채점하거나 안전성과 강건성 평가가 불충분하고 모달리티도 협소했다. Claw-Eval은 이런 세 가지 공백을 메우기 위해 설계된 엔드투엔드 평가 세트이며, 300개의 사람 검증 태스크를 포함해 더 신뢰성 있는 평가를 목표로 한다.
  • 링크: https://huggingface.co/papers/2604.06132

4. [AI생성] LIBERO-Para: VLA 모델의 패러프레이즈 강건성 진단 벤치마크와 지표

  • 원제: LIBERO-Para: A Diagnostic Benchmark and Metrics for Paraphrase Robustness in VLA Models
  • Upvotes: 75
  • 한줄 요약: 로봇용 VLA 모델이 문장 표현만 바뀌어도 성능이 흔들리는 문제를 겨냥해, 패러프레이즈 강건성을 정밀하게 측정하는 통제형 벤치마크를 제시한다.
  • 요약 번역: VLA 모델은 사전학습된 비전-언어 백본 덕분에 강한 조작 성능을 보이지만, 다운스트림 로봇 환경에서는 제한된 데이터로 파인튜닝되어 특정 지시문 표현에 과적합되기 쉽다. LIBERO-Para는 행동 표현과 객체 지시를 독립적으로 바꾸며, 문장 재서술에 대한 모델의 강건성을 통제된 조건에서 분석할 수 있게 한다.
  • 링크: https://huggingface.co/papers/2603.28301

5. [에이전트] 에이전트 궤적으로부터 검색을 학습하기

  • 원제: Learning to Retrieve from Agent Trajectories
  • Upvotes: 55
  • 한줄 요약: 사람 클릭 로그 대신 LLM 에이전트의 다중 턴 행동 궤적을 학습 신호로 사용해, 에이전트 친화적인 검색 모델을 만들자는 제안이다.
  • 요약 번역: 전통적인 정보검색 시스템은 사람 사용자의 클릭이나 체류 시간 같은 상호작용 로그를 기반으로 학습돼 왔다. 하지만 최근에는 검색이 인간이 아니라 LLM 에이전트의 추론·행동 루프 안에서 소비되는 경우가 늘고 있어, 기존 학습 목표가 더 이상 잘 맞지 않는다. 이 논문은 에이전트의 실제 trajectory를 활용해 검색기를 학습하는 방향을 제시한다.
  • 링크: https://huggingface.co/papers/2604.04949

6. [AI생성] ACES: 누가 테스트를 검증하는가? 코드 생성용 Leave-One-Out AUC 일관성

  • 원제: ACES: Who Tests the Tests? Leave-One-Out AUC Consistency for Code Generation
  • Upvotes: 46
  • 한줄 요약: LLM이 만든 테스트 자체가 틀릴 수 있다는 문제를 해결하기 위해, 테스트의 정오를 직접 판별하지 않고도 코드 후보 순위를 매기는 평가 방법을 제안한다.
  • 요약 번역: LLM이 생성한 코드 후보를 또 다른 LLM이 생성한 테스트로 고르는 과정은, 테스트가 잘못됐을 수 있다는 점에서 순환 의존성을 가진다. 기존 방법은 모든 테스트를 동일하게 다루거나 임시방편적 휴리스틱을 썼다. ACES는 테스트가 얼마나 많은 코드를 통과시키는지가 아니라, 코드 후보를 얼마나 일관되게 순위화하는지에 주목해 더 안정적인 선택 기준을 제시한다.
  • 링크: https://huggingface.co/papers/2604.03922

7. [에이전트] GBQA: QA 엔지니어로서 LLM을 평가하는 게임 벤치마크

  • 원제: GBQA: A Game Benchmark for Evaluating LLMs as Quality Assurance Engineers
  • Upvotes: 37
  • 한줄 요약: 동적 실행 환경이 필요한 버그 탐지를 게임 도메인으로 구체화해, LLM이 실제 QA 엔지니어처럼 결함을 찾아낼 수 있는지 평가한다.
  • 요약 번역: 현대 소프트웨어 개발에서 버그를 자율적으로 발견하는 일은 코드 생성보다 훨씬 어렵다. 특히 동적 런타임 환경을 이해해야 하기 때문이다. GBQA는 30개의 게임과 124개의 사람 검증 버그를 포함한 벤치마크를 구축해, LLM이 게임 QA 엔지니어처럼 실제 버그를 찾아낼 수 있는지 측정한다.
  • 링크: https://huggingface.co/papers/2604.02648

8. [AI생성] ThinkTwice: 추론과 자기 정제를 함께 최적화하는 대형 언어모델

  • 원제: ThinkTwice: Jointly Optimizing Large Language Models for Reasoning and Self-Refinement
  • Upvotes: 32
  • 한줄 요약: 문제를 푸는 단계와 자기 답을 다듬는 단계를 번갈아 최적화해, 별도 비평 주석 없이도 수학 추론 성능을 끌어올리는 2단계 학습 프레임워크다.
  • 요약 번역: ThinkTwice는 GRPO 기반의 단순한 2단계 프레임워크로, 먼저 추론 문제를 푸는 능력을 학습하고 이어서 같은 문제에 대한 자신의 해답을 스스로 개선하는 능력을 학습한다. 두 단계 모두 이진 정답 보상만 사용하며, 별도의 정답 경로 신호나 비평 주석이 없어도 자기 정제 능력을 함께 끌어올릴 수 있음을 보인다.
  • 링크: https://huggingface.co/papers/2604.01591

9. [영상] Vanast: 합성 삼중항 지도학습 기반 인간 이미지 애니메이션 가상 피팅

  • 원제: Vanast: Virtual Try-On with Human Image Animation via Synthetic Triplet Supervision
  • Upvotes: 29
  • 한줄 요약: 단일 인물 이미지와 의상 이미지, 포즈 가이드 비디오만으로 자연스러운 의상 교체 애니메이션을 한 번에 생성하는 통합 프레임워크다.
  • 요약 번역: 기존 가상 피팅-애니메이션 파이프라인은 의상 합성과 포즈 기반 애니메이션을 따로 처리해 인물 정체성 붕괴, 의상 왜곡, 앞뒤 불일치가 자주 발생했다. Vanast는 이 과정을 하나의 통합 단계로 수행해 더 일관된 사람 애니메이션 비디오를 생성하고, 합성 삼중항 데이터로 학습 안정성을 높인다.
  • 링크: https://huggingface.co/papers/2604.04934

10. [AI생성] 정확도를 넘어서: 툴 통합 추론의 비효율 패턴 드러내기

  • 원제: Beyond Accuracy: Unveiling Inefficiency Patterns in Tool-Integrated Reasoning
  • Upvotes: 29
  • 한줄 요약: 툴 호출이 잦은 LLM 추론에서 KV 캐시 재계산과 긴 툴 응답이 병목을 만든다는 점을 분석하고, 정확도 외의 효율 지표 필요성을 제기한다.
  • 요약 번역: 실제 툴 통합 추론 환경에서는 외부 도구 호출이 LLM 요청 사이에 긴 공백을 만들고, 이 과정에서 KV 캐시가 제거되어 반복 계산이 발생한다. 또한 도구가 반환하는 장문의 응답은 컨텍스트를 부풀려 디코딩 속도를 점점 떨어뜨린다. 이 논문은 정확도만으로는 드러나지 않는 TIR 시스템의 비효율 패턴을 분석하고 새로운 효율 평가 관점을 제시한다.
  • 링크: https://huggingface.co/papers/2604.05404
