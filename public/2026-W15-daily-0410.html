2. [에이전트] RAGEN-2: 에이전트형 RL에서의 추론 붕괴

  • 원제: RAGEN-2: Reasoning Collapse in Agentic RL
  • Upvotes: 42
  • 한줄 요약: 엔트로피가 멀쩡해 보여도 입력과 무관한 고정 추론 템플릿으로 무너질 수 있다는 점을 밝히고, 상호정보량 기반 진단과 필터링을 제안한다.
  • 요약 번역: 멀티턴 에이전트 RL에서는 보통 엔트로피로 추론 안정성을 보지만, 이 논문은 엔트로피가 높아도 모델이 입력별로 다르게 사고하지 않고 그럴듯한 템플릿만 반복하는 template collapse가 발생할 수 있음을 보인다. 이를 진단하기 위해 입력 내 다양성은 엔트로피, 입력 간 구분 가능성은 상호정보량으로 분해해 측정하고, 실제 성능과는 엔트로피보다 상호정보량이 더 강하게 상관된다고 주장한다. 또한 보상 분산이 낮으면 태스크 신호가 약해져 정규화 항이 우세해지고 입력 의존적 추론이 사라진다는 SNR 관점의 설명과 함께, 보상 분산이 큰 프롬프트를 우선 선택하는 SNR-Aware Filtering을 제안한다.
  • 링크: https://huggingface.co/papers/2604.06268

4. [AI생성] MegaTrain: 단일 GPU에서 100B+ LLM을 완전 정밀도로 학습하기

  • 원제: MegaTrain: Full Precision Training of 100B+ Parameter Large Language Models on a Single GPU
  • Upvotes: 38
  • 한줄 요약: 파라미터와 옵티마이저 상태를 CPU 메모리에 두고 GPU를 계산 엔진처럼 스트리밍 활용해, 단일 GPU에서도 100B급 학습을 가능하게 한다.
  • 요약 번역: MegaTrain은 기존처럼 GPU 메모리를 모델 상태의 상시 저장소로 쓰지 않고, CPU 메모리를 중심 저장소로 삼고 GPU에는 레이어별 파라미터를 불러와 계산 후 다시 내보내는 메모리 중심 학습 시스템이다. 병목인 CPU-GPU 대역폭 문제를 줄이기 위해 파라미터 프리패치·계산·그래디언트 오프로딩을 겹치는 이중 버퍼 파이프라인과, 가중치를 동적으로 바인딩하는 무상태 레이어 템플릿을 도입했다. 그 결과 단일 H200 + 1.5TB 호스트 메모리에서 120B 모델까지 완전 정밀도 학습이 가능했고, 14B 학습에서는 ZeRO-3 CPU offloading 대비 1.84배 처리량을 기록했다.

  • 요약 번역: 이 연구는 에이전트 스킬을 사람이 잘 골라서 바로 컨텍스트에 넣어주는 이상적 평가 대신, 3.4만 개의 실제 스킬 저장소에서 에이전트가 직접 검색·선택해야 하는 현실적 조건으로 벤치마크를 구성했다. 그 결과 조건이 현실에 가까워질수록 스킬의 성능 이득은 빠르게 줄어들고, 가장 어려운 설정에서는 무스킬 베이스라인에 가까워졌다. 다만 초기 검색 품질이 어느 정도 확보되면 쿼리별 스킬 정제가 손실된 성능을 상당 부분 회복시킬 수 있었고, Terminal-Bench 2.0에서도 Claude Opus 4.6의 통과율을 57.7%에서 65.5%로 끌어올렸다.

  • 요약 번역: 저자들은 장문 비디오 이해 벤치마크의 40~60%가 실제 비디오 없이 텍스트 단서만으로 답할 수 있다는 점을 보이며, 현재의 성능 향상이 진짜 시각 이해가 아니라 언어적 지름길에 크게 의존한다고 지적한다. 이를 해결하기 위해 시각적 근거가 실제로 필요한 질문만 선별한 VidGround 데이터를 구성하고, RL 기반 포스트트레이닝과 결합했을 때 전체 데이터를 쓸 때보다 더 적은 데이터로도 최대 6.2포인트 성능 향상을 얻었다. 핵심 메시지는 복잡한 학습 알고리즘보다 데이터 큐레이션 품질이 비디오 이해 성능 개선의 더 큰 병목이라는 것이다.

9. [3D재구성] 범용 멀티모달 단백질 설계가 화학의 DNA 인코딩을 가능하게 한다

  • Upvotes: 23

  • 요약 번역: 이 논문은 DISCO라는 멀티모달 생성모델을 제안해 단백질 서열과 3차원 구조를 동시에 설계하고, 반응 중간체 같은 화학 정보를 조건으로 새로운 헴 효소를 만든다. 기존 생성 모델이 결합 단백질 설계에는 성공했어도 촉매 잔기를 사전에 박아 넣지 않고 완전히 새로운 효소를 만든 사례는 없었는데, DISCO는 이를 가능하게 했다고 주장한다. 실제로 알켄 사이클로프로판화, 스피로사이클로프로판화, B-H 삽입, C(sp3)-H 삽입 같은 new-to-nature 반응을 높은 활성으로 촉매하는 효소를 설계했고, 후속 돌연변이 실험으로 진화 가능성도 확인했다.
