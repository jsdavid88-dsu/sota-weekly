## 🔍 주요 논문 상세

### 1. InCoder-32B: 산업 시나리오를 위한 코드 기반 모델
- **카테고리**: AI생성 | **Upvotes**: 132
- 320억 파라미터 규모의 코드 파운데이션 모델. 일반 코딩 벤치마크뿐 아니라 산업 현장의 실무 코딩 패턴(레거시 코드 리팩토링, 도메인 특화 API 활용 등)에서 기존 모델 대비 우수한 성능을 보임.

### 2. MiroThinker-1.7 & H1: 검증 기반 고강도 연구 에이전트
- **카테고리**: 에이전트 | **Upvotes**: 130
- 자율적으로 가설을 세우고, 실험을 설계하며, 결과를 검증하는 연구 에이전트. 단순 검색·요약이 아닌 능동적 연구 수행 능력이 핵심. 과학 연구 자동화의 새로운 단계.

### 3. Qianfan-OCR: 문서 지능 통합 모델
- **카테고리**: AI생성 | **Upvotes**: 79
- 기존에 분리되어 있던 문서 레이아웃 분석, 텍스트 인식, 키-값 추출을 하나의 종단간 모델로 통합. 복잡한 문서(표, 수식, 다단 레이아웃)에서도 높은 정확도.

### 4. Kinema4D: 운동학적 4D 세계 모델링
- **카테고리**: 3D재구성 | **Upvotes**: 62
- 물리적 운동학 원리를 4D(3D+시간) 세계 모델에 내재화. 로봇 시뮬레이션, 체화 AI 학습 환경 구축에 직접 활용 가능. **핵심 관련 연구**: Gaussian Splatting 기반 4D 재구성과 결합 시 UE5 파이프라인에 시너지.

### 5. 비디오 추론의 신비를 벗기다
- **카테고리**: 영상 | **Upvotes**: 55
- 현재 멀티모달 모델들의 비디오 추론 능력을 체계적으로 벤치마킹. 시간적 인과관계, 행동 예측, 장면 이해 등에서의 강점과 약점을 분류하고 개선 방향 제시. **핵심 관련 연구**: 부산마법소녀 VFX 씬 분석·생성 품질 평가에 참고 가능.

### 6. 불확실성 속 사고: 잠재 엔트로피 인식 디코딩
- **카테고리**: AI생성 | **Upvotes**: 50
- 모델이 "확신이 낮은" 토큰을 생성할 때를 실시간 감지하여 디코딩 전략을 동적 조정. 환각 발생률을 유의미하게 감소시키면서 생성 품질은 유지.

### 7. TRUST-SQL: 미지 스키마 Text-to-SQL 강화학습
- **카테고리**: 에이전트 | **Upvotes**: 43
- 스키마를 사전에 알지 못하는 현실적 상황에서, 에이전트가 도구(스키마 탐색, 쿼리 테스트 등)를 활용하며 다중 턴으로 SQL을 점진적으로 완성하는 강화학습 프레임워크.

### 8. WorldCam: 인터랙티브 자기회귀 3D 게임 월드
- **카테고리**: 3D재구성 | **Upvotes**: 43
- 카메라 포즈 자체를 기하학적 표현의 핵심 축으로 삼아, 사용자 입력에 반응하는 3D 게임 월드를 자기회귀적으로 생성. **핵심 관련 연구**: 실시간 3D 콘텐츠 생성 → UE5 연동 파이프라인 참고.

### 9. FinToolBench: 금융 도구 활용 LLM 에이전트 평가
- **카테고리**: 에이전트 | **Upvotes**: 31
- 실제 금융 데이터 API, 계산 도구, 데이터베이스를 활용하는 복합 과제에서 LLM 에이전트를 평가하는 벤치마크. 도구 선택 정확도, 다단계 추론 능력이 핵심 평가 지표.

### 10. WiT: 궤적 충돌 탐색 기반 웨이포인트 확산 트랜스포머
- **카테고리**: 3D재구성 | **Upvotes**: 28
- 복잡한 환경에서 장애물 회피 경로를 생성하는 확산 트랜스포머. 궤적 충돌을 명시적으로 모델링하여 안전하고 효율적인 내비게이션 경로를 생성.
