## 논문별 짧은 번역 메모

### 1. SLA2: 학습 가능한 라우팅과 QAT를 결합한 희소-선형 어텐션
- 원제: SLA2: Sparse-Linear Attention with Learnable Routing and QAT
- 요약 번역: 비디오 생성에서 쓰이는 Sparse-Linear Attention은 빠르지만, 어떤 계산을 희소 분기와 선형 분기에 보낼지 정하는 휴리스틱이 비효율적일 수 있다. 이 논문은 그 분기 자체를 학습 가능하게 만들고, 양자화 인지 학습(QAT)까지 결합해 가속 성능과 생성 품질을 함께 개선하려는 방법을 제안한다.

### 2. AutoWebWorld: 유한 상태 기계로 무한히 검증 가능한 웹 환경 합성
- 원제: AutoWebWorld: Synthesizing Infinite Verifiable Web Environments via Finite State Machines
- 요약 번역: 웹 GUI 에이전트는 대량의 상호작용 데이터가 필요하지만, 실제 웹에서 이를 수집하고 정답을 검증하는 일은 비싸고 어렵다. 이 연구는 유한 상태 기계를 기반으로 상태 전이가 명확한 합성 웹 환경을 자동 생성해, 무한에 가까운 학습 데이터를 검증 가능하게 공급하는 방식을 제시한다.

### 3. SpargeAttention2: 하이브리드 Top-k+Top-p 마스킹과 증류 파인튜닝을 통한 학습형 희소 어텐션
- 원제: SpargeAttention2: Trainable Sparse Attention via Hybrid Top-k+Top-p Masking and Distillation Fine-Tuning
- 요약 번역: 기존의 학습 없는 희소 어텐션은 확산 모델을 빠르게 만들지만, 마스킹 규칙이 상황에 따라 쉽게 실패할 수 있다. 이 논문은 Top-k와 Top-p를 결합한 마스킹과 증류 기반 파인튜닝을 통해, 더 공격적으로 희소화하면서도 생성 품질을 유지하는 학습형 희소 어텐션을 제안한다.

### 4. RynnBrain: 오픈소스 체화형 파운데이션 모델
- 원제: RynnBrain: Open Embodied Foundation Models
- 요약 번역: 멀티모달 파운데이션 모델이 빠르게 발전했지만, 실제 공간과 시간 속에서 움직이는 체화형 지능을 위한 통합 기반 모델은 여전히 부족하다. RynnBrain은 지각, 추론, 계획을 하나의 시공간 모델 안에서 다루는 오픈소스 체화형 파운데이션 모델로 제시된다.

### 5. Mobile-Agent-v3.5: 멀티플랫폼 범용 GUI 에이전트
- 원제: Mobile-Agent-v3.5: Multi-platform Fundamental GUI Agents
- 요약 번역: 최신 GUI 에이전트 모델 계열은 여러 크기와 지시형/사고형 변형을 지원하며, 데스크톱·모바일·브라우저 등 다양한 환경에서 동작한다. 이 논문은 이러한 멀티플랫폼 GUI 에이전트가 20개 이상 벤치마크에서 강한 성능을 보인다고 주장한다.

### 6. Unified Latents (UL): 잠재표현을 제대로 학습하는 법
- 원제: Unified Latents (UL): How to train your latents
- 요약 번역: 이 논문은 디퓨전 프라이어로 정규화되고 디퓨전 모델로 복원되는 잠재표현을 학습하는 프레임워크를 제안한다. 인코더 출력 노이즈와 프라이어의 최소 노이즈 수준을 연결해, 잠재 비트율에 대한 타이트한 상한을 제공하는 단순한 학습 목표를 구성한다.

### 7. 현장 적용 중심 Frontier AI 위험관리 프레임워크: 위험 분석 기술보고서 v1.5
- 원제: Frontier AI Risk Management Framework in Practice: A Risk Analysis Technical Report v1.5
- 요약 번역: 빠르게 발전하는 프런티어 AI와 에이전트형 AI가 초래할 수 있는 위험을 이해하고 식별하기 위해, 실제 운영 맥락에서 활용 가능한 위험 분석 프레임워크를 정리한 기술 보고서다. 최신 위험 유형과 관리 관행을 업데이트해 실무 적용성을 높이는 데 초점을 둔다.

### 8. 오픈 보캐뷸러리 시각 보행-조작을 위한 휴머노이드 말단효과기 제어 학습
- 원제: Learning Humanoid End-Effector Control for Open-Vocabulary Visual Loco-Manipulation
- 요약 번역: 야외와 실제 환경의 다양한 물체를 다루는 휴머노이드 로봇에는 정밀한 말단효과기 제어와 일반화 가능한 시각 이해가 필요하다. 이 연구는 RGB-D 기반 시각 입력을 활용해, 대규모 실제 모방 데이터의 한계를 넘는 새로운 제어 학습 방식을 제안한다.

### 9. CADEvolve: 프로그램 진화로 더 현실적인 CAD 생성하기
- 원제: CADEvolve: Creating Realistic CAD via Program Evolution
- 요약 번역: 기존 공개 CAD 데이터는 단순한 스케치-익스트루드 중심이라 복잡한 설계 의도와 다단계 조작을 충분히 담지 못한다. 이 논문은 CAD 생성을 프로그램 진화 문제로 다뤄 더 현실적이고 편집 가능한 설계를 자동 생성하려는 방향을 제시한다.

### 10. Clawdbot(OpenClaw) 궤적 기반 안전 감사
- 원제: A Trajectory-Based Safety Audit of Clawdbot (OpenClaw)
- 요약 번역: OpenClaw처럼 도구를 직접 사용하는 개인 AI 에이전트는 로컬 실행과 웹 상호작용 때문에 넓은 행동 공간과 높은 위험을 가진다. 이 연구는 여섯 가지 위험 축에서 실제 행동 궤적을 평가해, 에이전트 안전성을 정량적으로 감사하는 테스트 체계를 제안한다.
