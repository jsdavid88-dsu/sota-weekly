## 1. [AI생성] 픽셀이 아니라 붓질로 생각하라: 인터리브드 추론 기반 프로세스 주도 이미지 생성
- **원제:** Think in Strokes, Not Pixels: Process-Driven Image Generation via Interleaved Reasoning
- **Upvotes:** 45
- **한줄 요약:** 최종 이미지를 한 번에 뽑는 대신 계획→스케치→점검→정제의 반복 루프로 중간 시각 상태를 추론에 연결하는 생성 프레임워크다.
- **요약 번역:** 이 논문은 이미지 생성을 단발성 출력이 아니라 여러 단계의 사고와 시각적 중간 상태가 맞물리는 과정으로 재정의한다. 각 반복 단계에서 텍스트 계획, 시각 초안, 텍스트 반성, 시각 정제를 수행하며, 이전 단계에서 생성된 이미지가 다음 추론의 근거가 된다. 저자들은 중간 결과의 모호성을 다루기 위해 시각 상태에는 공간적·의미적 일관성을, 텍스트 상태에는 기존 시각 정보 보존과 오류 수정 능력을 동시에 강제하는 조밀한 단계별 감독을 제안한다.
- **링크:** https://huggingface.co/papers/2604.04746

## 2. [에이전트] RAGEN-2: 에이전트형 RL에서의 추론 붕괴
- **원제:** RAGEN-2: Reasoning Collapse in Agentic RL
- **Upvotes:** 42
- **한줄 요약:** 엔트로피가 멀쩡해 보여도 입력과 무관한 고정 추론 템플릿으로 무너질 수 있다는 점을 밝히고, 상호정보량 기반 진단과 필터링을 제안한다.
- **요약 번역:** 멀티턴 에이전트 RL에서는 보통 엔트로피로 추론 안정성을 보지만, 이 논문은 엔트로피가 높아도 모델이 입력별로 다르게 사고하지 않고 그럴듯한 템플릿만 반복하는 `template collapse`가 발생할 수 있음을 보인다. 이를 진단하기 위해 입력 내 다양성은 엔트로피, 입력 간 구분 가능성은 상호정보량으로 분해해 측정하고, 실제 성능과는 엔트로피보다 상호정보량이 더 강하게 상관된다고 주장한다. 또한 보상 분산이 낮으면 태스크 신호가 약해져 정규화 항이 우세해지고 입력 의존적 추론이 사라진다는 SNR 관점의 설명과 함께, 보상 분산이 큰 프롬프트를 우선 선택하는 SNR-Aware Filtering을 제안한다.
- **링크:** https://huggingface.co/papers/2604.06268

## 3. [에이전트] GBQA: QA 엔지니어로서 LLM을 평가하는 게임 벤치마크
- **원제:** GBQA: A Game Benchmark for Evaluating LLMs as Quality Assurance Engineers
- **Upvotes:** 39
- **한줄 요약:** 코드 생성보다 훨씬 어려운 자율 버그 탐지를 게임 도메인으로 정식 벤치마크화한 연구다.
- **요약 번역:** 저자들은 소프트웨어 자동화에서 아직 비어 있는 영역이 `버그 발견`이라고 보고, 30개 게임과 124개의 인간 검증 버그를 포함한 게임 QA 벤치마크를 구축했다. 이 벤치마크는 다중 에이전트 시스템으로 게임과 버그를 대규모 생성한 뒤 사람 검증으로 품질을 확보했고, 멀티라운드 ReAct 루프와 메모리 메커니즘을 갖춘 베이스라인 에이전트도 함께 제공한다. 실험 결과 최상위 모델도 검증된 버그의 절반 이하만 찾았으며, 자율 QA는 아직 코드 생성보다 훨씬 어렵다는 점을 보여준다.
- **링크:** https://huggingface.co/papers/2604.02648

## 4. [AI생성] MegaTrain: 단일 GPU에서 100B+ LLM을 완전 정밀도로 학습하기
- **원제:** MegaTrain: Full Precision Training of 100B+ Parameter Large Language Models on a Single GPU
- **Upvotes:** 38
- **한줄 요약:** 파라미터와 옵티마이저 상태를 CPU 메모리에 두고 GPU를 계산 엔진처럼 스트리밍 활용해, 단일 GPU에서도 100B급 학습을 가능하게 한다.
- **요약 번역:** MegaTrain은 기존처럼 GPU 메모리를 모델 상태의 상시 저장소로 쓰지 않고, CPU 메모리를 중심 저장소로 삼고 GPU에는 레이어별 파라미터를 불러와 계산 후 다시 내보내는 메모리 중심 학습 시스템이다. 병목인 CPU-GPU 대역폭 문제를 줄이기 위해 파라미터 프리패치·계산·그래디언트 오프로딩을 겹치는 이중 버퍼 파이프라인과, 가중치를 동적으로 바인딩하는 무상태 레이어 템플릿을 도입했다. 그 결과 단일 H200 + 1.5TB 호스트 메모리에서 120B 모델까지 완전 정밀도 학습이 가능했고, 14B 학습에서는 ZeRO-3 CPU offloading 대비 1.84배 처리량을 기록했다.
- **링크:** https://huggingface.co/papers/2604.05091

## 5. [영상] Vanast: 합성 삼중항 지도학습 기반 인간 이미지 애니메이션 가상 피팅
- **원제:** Vanast: Virtual Try-On with Human Image Animation via Synthetic Triplet Supervision

- **요약 번역:** 기존 가상 피팅과 포즈 기반 애니메이션은 보통 2단계 파이프라인으로 분리되어 정체성 붕괴, 의상 왜곡, 시점 불일치가 자주 발생했다. Vanast는 이 과정을 하나의 통합 생성 단계로 묶고, 인물 이미지·의상 이미지·동작 비디오의 삼중항 감독 데이터를 합성 방식으로 구축해 학습 가능하게 만든다. 여기에 비디오 디퓨전 트랜스포머용 듀얼 모듈 구조를 도입해 의상 정확도, 포즈 일치, 정체성 보존을 함께 개선하고 zero-shot 의상 보간까지 지원한다.

## 6. [AI생성] ThinkTwice: 추론과 자기 정제를 함께 최적화하는 대형 언어모델
- **원제:** ThinkTwice: Jointly Optimizing Large Language Models for Reasoning and Self-Refinement
- **Upvotes:** 33
- **한줄 요약:** 문제 풀이와 자기 답 수정 단계를 번갈아 학습시켜, 외부 비평 없이도 추론과 자기 교정 능력을 동시에 키운다.
- **요약 번역:** ThinkTwice는 GRPO 기반 2단계 학습으로 먼저 문제를 푸는 정책을 강화하고, 이어 같은 문제에 대한 자신의 해답을 스스로 수정하는 정책을 학습한다. 두 단계 모두 정답 여부만을 쓰는 이진 보상을 사용하며, 정답 풀이 과정이나 비평 주석 없이도 자기 정제 능력을 학습할 수 있게 설계됐다. 실험에서는 여러 수학 추론 벤치마크에서 기존 온라인 정책 최적화보다 초기 답안 성능과 한 번의 자기 정제 후 성능 모두를 끌어올렸고, 학습 초반에는 오류 수정 중심, 후반에는 올바른 해답 보강 중심으로 이동하는 `rectify-then-fortify` 패턴도 관찰했다.
- **링크:** https://huggingface.co/papers/2604.01591

## 7. [에이전트] 실제 환경에서 에이전트 스킬은 얼마나 잘 작동하는가
- **원제:** How Well Do Agentic Skills Work in the Wild: Benchmarking LLM Skill Usage in Realistic Settings
- **Upvotes:** 31
- **한줄 요약:** 실제 대규모 스킬 저장소에서 검색과 선택까지 포함하면, 스킬의 효과가 기대만큼 강하지 않다는 걸 보여주는 현실형 벤치마크다.
- **요약 번역:** 이 연구는 에이전트 스킬을 사람이 잘 골라서 바로 컨텍스트에 넣어주는 이상적 평가 대신, 3.4만 개의 실제 스킬 저장소에서 에이전트가 직접 검색·선택해야 하는 현실적 조건으로 벤치마크를 구성했다. 그 결과 조건이 현실에 가까워질수록 스킬의 성능 이득은 빠르게 줄어들고, 가장 어려운 설정에서는 무스킬 베이스라인에 가까워졌다. 다만 초기 검색 품질이 어느 정도 확보되면 쿼리별 스킬 정제가 손실된 성능을 상당 부분 회복시킬 수 있었고, Terminal-Bench 2.0에서도 Claude Opus 4.6의 통과율을 57.7%에서 65.5%로 끌어올렸다.
- **링크:** https://huggingface.co/papers/2604.04323

## 8. [영상] 대답하기 전에 먼저 보라: 시각적으로 접지된 포스트트레이닝으로부터 학습하기
- **원제:** Watch Before You Answer: Learning from Visually Grounded Post-Training
- **Upvotes:** 27
- **한줄 요약:** 비디오 이해 벤치마크 상당수가 사실 텍스트만으로도 풀린다는 문제를 짚고, 진짜 시각 근거가 필요한 데이터만 골라 후학습하는 방법을 제안한다.
- **요약 번역:** 저자들은 장문 비디오 이해 벤치마크의 40~60%가 실제 비디오 없이 텍스트 단서만으로 답할 수 있다는 점을 보이며, 현재의 성능 향상이 진짜 시각 이해가 아니라 언어적 지름길에 크게 의존한다고 지적한다. 이를 해결하기 위해 시각적 근거가 실제로 필요한 질문만 선별한 VidGround 데이터를 구성하고, RL 기반 포스트트레이닝과 결합했을 때 전체 데이터를 쓸 때보다 더 적은 데이터로도 최대 6.2포인트 성능 향상을 얻었다. 핵심 메시지는 복잡한 학습 알고리즘보다 데이터 큐레이션 품질이 비디오 이해 성능 개선의 더 큰 병목이라는 것이다.
- **링크:** https://huggingface.co/papers/2604.05117

## 9. [3D재구성] 범용 멀티모달 단백질 설계가 화학의 DNA 인코딩을 가능하게 한다
- **원제:** General Multimodal Protein Design Enables DNA-Encoding of Chemistry
- **Upvotes:** 23
- **한줄 요약:** 서열과 3D 구조를 함께 설계하는 멀티모달 생성모델로, 촉매 잔기를 미리 지정하지 않고도 새로운 효소 화학 반응을 설계한다.
- **요약 번역:** 이 논문은 DISCO라는 멀티모달 생성모델을 제안해 단백질 서열과 3차원 구조를 동시에 설계하고, 반응 중간체 같은 화학 정보를 조건으로 새로운 헴 효소를 만든다. 기존 생성 모델이 결합 단백질 설계에는 성공했어도 촉매 잔기를 사전에 박아 넣지 않고 완전히 새로운 효소를 만든 사례는 없었는데, DISCO는 이를 가능하게 했다고 주장한다. 실제로 알켄 사이클로프로판화, 스피로사이클로프로판화, B-H 삽입, C(sp3)-H 삽입 같은 new-to-nature 반응을 높은 활성으로 촉매하는 효소를 설계했고, 후속 돌연변이 실험으로 진화 가능성도 확인했다.
- **링크:** https://huggingface.co/papers/2604.05181

## 10. [에이전트] Combee: 자기 개선형 언어모델 에이전트를 위한 프롬프트 학습의 확장
- **원제:** Combee: Scaling Prompt Learning for Self-Improving Language Model Agents
- **Upvotes:** 21
- **한줄 요약:** 다수의 에이전트 실행 흔적을 병렬로 반영해도 품질 저하 없이 프롬프트 학습을 가속하는 프레임워크다.
- **요약 번역:** 기존 ACE, GEPA류 프롬프트 학습은 순차적이거나 저병렬 환경에 맞춰져 있어 대량의 에이전트 trajectory를 동시에 활용하기 어렵다. Combee는 병렬 스캔, augmented shuffle, 동적 배치 크기 제어를 결합해 많은 에이전트가 동시에 생성한 흔적을 품질 저하 없이 집계하고, 프롬프트 학습 자체를 고병렬로 확장한다. AppWorld, Terminal-Bench, Formula, FiNER 평가에서 기존 방법보다 최대 17배 빠르면서도 정확도와 비용은 동등하거나 더 나은 결과를 보였다.
- **링크:** https://huggingface.co/papers/2604.04247
